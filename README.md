# Welcome to My Spring Portfolio - Fund Investment Platform
***

## Task
**The Problem:** Individual investors often struggle to track, analyze, and optimize their fund investments effectively. Traditional financial management tools are either overly complex, require manual data entry, or fail to provide unified, real-time insights into portfolio health, asset allocation, and overall returns.

**The Challenge:** The challenge lies in building a robust, secure, and highly responsive full-stack financial application. This requires handling complex real-time mathematical calculations (such as total ROI, weighted asset allocation, and historical performance metrics) on a secure Java backend, while simultaneously delivering a seamless, low-latency, and interactive data visualization experience on a modern web frontend.

## Description
This project is a comprehensive Fund Investment Platform engineered with a scalable, decoupled architecture to solve the core challenges of modern portfolio management:

*   **Back-end (Spring Boot):** Serves as the core financial engine. Developed in Java, it leverages Spring Security and JWT for secure authentication, Spring Data JPA for object-relational mapping, and a relational database to handle complex transactions. It exposes a robust RESTful API that handles business logic, automated financial calculations, and secure data storage.
*   **Front-end (Next.js):** Built with React and TypeScript, the frontend consumes the backend REST APIs to deliver a high-fidelity dashboard. It utilizes Next.js routing and server-side capabilities for rapid page loads, while client-side components provide interactive data visualizations, live portfolio statistics, and fluid transaction forms.

## Installation

### Prerequisites
Before running the application, ensure you have the following installed:
*   Java JDK 17 or higher
*   Apache Maven 3.8+
*   Node.js v18.0.0 or higher
*   npm (Node Package Manager)
